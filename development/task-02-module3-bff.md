# 任务 02：模块 3 后台 BFF 接口

## 目标

为运营区域、站点与运营时段管理页面提供受 JWT 和 Casbin 保护的后台私有接口。

## 范围

- 新增 API、服务转发和私有路由注册。
- 不改微服务协议、数据库、核心鉴权或 SQL。

## 风险

- BFF 不能把微服务地址或原始错误返回给浏览器。
- 所有接口必须注册在 `PrivateGroup`，保持现有 JWT 与 Casbin 保护。
- 微服务当前返回 Proto 枚举文本，BFF 已兼容为管理端使用的数值状态；联调时仍需验证真实请求链路。
